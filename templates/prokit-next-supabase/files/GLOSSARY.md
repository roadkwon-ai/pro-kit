# 서비스 이름

이 서비스가 무엇이고 왜 존재하는지 한두 문장으로 적는다.

## Language

용어마다 한두 문장 정의와 피해야 할 동의어를 적는다. 일반 프로그래밍 개념과 코드 이름(테이블, 프로시저, 파일)은 넣지 않는다. 용어와 코드 이름은 `docs/domain/project.md` 표의 `용어` 칸에서 잇는다. 용어가 늘고 자연스러운 무리가 보이면 `###` 소제목(예: 액터, 주문, 결제)으로 묶는다. 형식은 `domain-modeling` 스킬의 GLOSSARY 형식을 따른다.

**사용자(User)**:
이 서비스에 가입해 자기 데이터를 가진 사람.
_Avoid_: 회원, 유저, account
