설치 전

여름 저녁에 에어컨을 켜면 한 달 사용량이 450kWh까지 올라 전기요금이 3단계 구간에 들어갔습니다.

지붕의 6kW 태양광이 낮에 만든 전기는 집에서 쓰고 남은 만큼 전력망으로 나가고 있었습니다.

설치하는 날

현관 옆 벽이 118kg을 버티는지 먼저 확인하고, 브래킷을 고정할 앵커 네 곳을 잡았습니다.

분전함까지 배선을 잇는 동안 약 2시간 전기가 끊겼습니다. 설치는 약 6시간 걸렸고 같은 날 앱 연결까지 마쳤습니다.
