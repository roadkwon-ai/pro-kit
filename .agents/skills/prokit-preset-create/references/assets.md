# 자산 계획

관측 요소마다 사진·표지·아이콘·영상·모션의 역할, 비율, 크롭, 색·조명, 포즈, 해상도와 출처를 기록한다. 필요한 수량은 원본 역할에서 결정한다. 회색 박스·아이콘·설명문이 사진을 대신하면 미완성이다.

사용이 승인된 원본 자산을 재사용하거나, 교체가 필요한 자산은 설치된 이미지 생성 스킬을 읽고 제작한다. 인물 연속성은 기준 이미지를 유지한다. 표지의 읽을 글자는 편집 가능한 레이어로 구성한다. 생성 결과를 실제 화면 크롭으로 검토하고 프롬프트·출처·파일 해시를 남긴다.

모션 그래픽은 원본에 실제 존재하고 필요한 경우에만 추가한다. CSS·SVG·기존 컴포넌트로 충분하면 재사용한다. 영상 생성이 필요하면 해당 도구 스킬의 절차와 비용·권한 범위를 따른다. 생성 영상의 길이·반복·첫 프레임·모바일·reduced-motion 대체도 검증한다. 원본에 없는 화려한 효과를 COPY 품질 개선으로 간주하지 않는다.

원본 영상을 사용하는 경우 관측한 제공자 ID·제목·순서를 source ID와 증거에 연결한다. 임베드 URL 형식과 카드 개수가 맞아도 임의의 영상 ID로 채우면 COPY 완료가 아니다. 의도적으로 교체한다면 새 자산의 출처와 허용 차이를 기록한다.

재사용 프리셋은 사용자가 소유한 콘텐츠를 제공하거나 원본 유지를 명시한 경우 외에는 고품질 가상 이미지·썸네일과 비어 있는 사용자 편집용 URL을 기본으로 한다. 원본 실인물·영상·미디어 URL의 자동 이식을 COPY로 간주하지 않는다. 앞의 원본 영상 ID 대조는 원본 영상 사용이 명시된 경우에 적용한다.

원본 판매 링크의 목적은 유지한다. URL 미설정 샘플은 비활성·링크 미설정 상태로 표시하며 가짜 # 주소나 임의 설명 팝업으로 대신하지 않는다. 실제 URL 등록 뒤에는 연결 목적지까지 확인한다. 실서비스 결제 전송을 제외하더라도 원본에 연결된 결제 UI·plan 상태는 조사 범위에 따라 데모 화면으로 구현한다.

글자가 박힌 표지·이미지는 생성 전 제품 canonical 한국어 title/author를 지정하고, 생성·편집 뒤 개별 이미지를 실제로 열어 글자를 대조한다. 예쁜 이미지나 loaded 상태만으로 완료하지 않는다. 영어 본문은 번역 정본, 한국어 표지는 한국어 정본에 각각 바인딩한다. 원본 책 제목·실인물을 그대로 쓰는 것은 명시적 사용자 보존 요청이 있을 때만 허용하며, 기본 가상 콘텐츠 정책을 유지한다.

## 구성 보존과 가상 콘텐츠

가상화는 원본의 정보 슬롯을 삭제하는 작업이 아니다. 푸터까지 전체 구성을 조사하고 각 슬롯의 역할·순서·그룹·링크 목적은 보존한 채 이름·소개·후기·이미지·연락처·사업자 정보를 일관된 가상 정본으로 바꾼다. 원본에 없는 항목을 일괄 추가하지 않는다. 소셜, 저작권, 상호·대표자·사업자등록번호·통신판매업신고·주소·전화·이메일과 정책 링크가 있으면 각각 대응한다. 반복 노출되는 정보도 모든 페이지와 언어에서 같은 정본을 읽는다. 반복 정보의 값은 공통 정본으로 관리하되 페이지별 마크업까지 같게 만들지는 않는다. 각 페이지에서 관측한 라벨·구분자·줄 배치·자간을 유지하고, 필드가 같다는 이유로 하나의 푸터 모양으로 합치지 않는다.

등록번호·전화·주소는 실제 사업체로 오인되지 않는 명확한 예시 값(예: `000-00-00000`, `제0000-예시-0000호`, `가상시 예시로 00`, `000-0000-0000`)을 쓰고 샘플 표시를 제공한다. 이메일은 `hello@example.com`처럼 예약 예시 도메인을 사용한다. URL은 사용자 편집용 빈 값으로 두고 미설정일 때 비활성 상태를 유지한다. 소셜 이름·색·슬롯은 보존하되 아이콘 자산은 프로젝트의 로고·상표 사용 규칙을 따른다. 원본 실정보를 다른 슬롯에 옮기거나 단순 면책 문구 뒤에 남기지 않는다.

관측 목록의 `contentSlots`에 슬롯 key·원본 value·변경 mode를 기록하고 제품 실제 값과 대조한다. 이 목록은 비공개 조사 증거이며 원본 실정보를 완성팩에 포함하기 위한 데이터가 아니다. 문서 담당에게는 제품 가상 정본 위치·교체 항목·미설정 링크 동작을 인계한다.
