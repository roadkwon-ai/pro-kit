# 원본 조사

[관측 계약](references/browser-observation.md)을 읽고 사용자가 지정한 Ego Browser 스킬의 실제 설치본을 먼저 읽는다. Ego가 없으면 제한과 대체 조사 범위를 보고한다. 정지 이미지로 동적 상태를 추정하지 않는다.

가상화할 사업자·연락 정보는 예시임이 명확한 무효 번호·가상 지역명·예약 도메인 `example.com`으로 대체하도록 인계한다. 실제일 수 있는 주소·전화·새 운영 도메인을 만들어 채우지 않으며, SOURCES·provenance의 원본 출처 URL은 별도로 보존한다.

원본의 전체 페이지를 데스크톱과 모바일로 순회한다. 푸터·반복 사업자 정보·소셜·저작권·정책 링크도 개별 슬롯과 순서를 기록한다. 메뉴·탭·슬라이더·카드·폼·영상·FAQ·sticky·hover·실제 휠 스크롤을 조사한다. 폼을 제출하거나 구매하지 않는다. 앵커 점프만으로 스크롤 모션을 조사했다고 하지 않는다.

관측은 직접 추출·측정·미확인을 구분한다. CSS와 화면을 함께 보고 서체 로딩·weight·행간·자간·폭·간격·색·효과·이미지 크롭·반응형 전환을 기록한다. 영상이나 모션은 시작·중간·끝·재진입·반복 조건을 관측한다.

구현 전 독립 연구자가 원본을 다시 순회해 목록 밖 누락을 추가한다. 보고에는 확인한 URL·상태·환경·원시 증거·남은 미확인을 포함한다. 이 결과를 prokit-preset-create에 인계하며 미확인을 없음이나 성공으로 바꾸지 않는다.
