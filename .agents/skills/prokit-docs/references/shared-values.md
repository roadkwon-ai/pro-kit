# 공통 값과 글 묶음

pro-kit은 여러 문서에 나오는 값과 글을 정본 한 곳에 두고, 문서에는 표시를 달아 스크립트가 채우게 한다. 규칙의 정본은 pro-kit `docs/common-values.md`의 "규칙" 절이다. 값이나 묶음을 다루기 전에 그 절을 끝까지 읽는다. 이 파일은 판단 순서와 명령만 둔다. 둘이 다르면 그 절을 따른다.

## 판단 순서

1. **두 곳 이상에 나오거나 자주 바뀌나?** 아니면 맨값과 맨글로 둔다. 맞으면 2번으로.
2. **한 줄 안의 값인가?** 값 표시 `<!-- v:키 -->값<!-- /v -->`로 쓴다. 키는 `node scripts/doc-values.mjs --list`로 찾는다. 없으면 정본에 먼저 더한다. 손으로 정하는 값은 `doc-values.json`, 파일에서 셀 수 있는 값은 `scripts/doc-values.mjs`의 `loadValues`다.
3. **여러 줄 글인가?** 글 묶음 `docs/blocks/<이름>.md`를 만들고 문서에는 `<!-- b:이름 키=값 -->` 줄과 `<!-- /b -->` 줄을 둔다. 묶음 원본의 첫 줄 주석은 설명이고, `{{키}}`는 인자, `{{v:키}}`는 값이다.
4. **목록이나 표의 중간인가?** 표시를 달면 목록과 표가 갈라진다. 표시 없이 묶음 원본과 같은 글로 두고 `scripts/doc-values.cases.mjs`의 CASES에 `[파일, 묶음 이름, 인자]`를 더한다. 목록이나 표 전체면 전체를 묶음으로 한다.
5. **시간인가?** 두 곳 이상에 쓰거나 자주 바뀌는 시간은 값 키로 쓴다. 한 곳에만 쓰고 바뀌지 않는 시간은 맨값으로, 시간 값이 아닌 말은 맨글로 두고 `docs/time-allow.txt`에 이유와 함께 적는다.
6. **링크 주소나 코드 블록 안인가?** 표시를 달 수 없다. 공개 주소는 `site-links.json`이 정본이고 `node scripts/site-links.mjs set <키> <주소>`로 바꾼 뒤 `node scripts/doc-values.mjs`를 돌린다. 코드 블록(Mermaid 포함)은 블록 전체를 묶음으로 한다.
7. **인라인 코드 안의 값인가?** 코드 한 덩어리가 값 전체면 백틱까지 담은 `…Code` 키를 코드 바깥에 단다. 코드의 일부만 값이면 표시를 달 수 없으니 그대로 두고 `docs/common-values.md`의 후보 절에 남긴다.
8. **정당한 반복인가?** `docs/dupes-allow.txt`에 이유와 함께 둔다. 이유 없이 더하지 않는다.

## 표시를 달지 않는 곳

- `templates/*/files/`: 새 프로젝트에 그대로 복사되는 설치본이다. 값이 정본과 같아야 하는 곳은 테스트가 비교한다.
- `release/`, `docs/superpowers/`: 지난 기록이다.
- 제목 줄은 예외로 달 수 있다. 앵커는 주석을 지운 글로 계산되므로, 그 앵커를 가리키는 링크 주소는 맨글로 쓴다.
- `docs/common-values.md`의 목록 표(`<!-- doc-values:list -->` 아래)는 `node scripts/doc-values.mjs`가 만든다. 손으로 고치지 않는다. 표의 뜻 칸은 값을 정하는 곳(`scripts/doc-values.mjs`의 `loadValues`)이나 묶음 원본의 첫 줄 설명에서 고친다.

## 자주 쓰는 꼴

- 이름이 바뀌는 묶음은 이름 뒤 조사를 인자 `neun`(는/은), `reul`(를/을), `ga`(가/이)로 받는다.
- 묶음 원본의 상대 링크는 쓰는 쪽 위치를 따른다. 같은 깊이의 쪽에서만 쓴다.
- 범위의 물결표는 `\~`로 쓴다.
- 요약 시간("얼마나 걸리나")은 맨값으로 쓰지 않고 계산값 `.text`(문장)와 `.cell`(표 칸)을 쓴다. 단계별 표의 칸은 최솟값이고 합계 행만 `.cell`이다. 토큰과 달러는 최솟값만 쓰고 최소임을 밝힌다.

## 명령

채우기(`node scripts/doc-values.mjs`), 확인(`--check`), 키 목록(`--list`), 테스트 명령은 `SKILL.md`의 검사 명령 표에 있다.

값은 정본에서만 바꾼다. 문서의 표시 안 값을 손으로 고치면 다음 실행에서 정본 값으로 돌아간다.

쪽을 다 쓰면 그 쪽에서 쓴 정본 값(포트, 판, 개수 등)을 글자로 찾아본다. 한 곳에 표시를 달고 다른 곳을 맨값으로 남기기 쉽다. 코드 블록 안의 값은 6번, 인라인 코드 안의 값은 7번을 따른다.

이 장치는 pro-kit 저장소에만 있다. pro-kit-web은 pro-kit이 내보낸 값을 읽고, 다른 저장소는 그 저장소의 규칙을 따른다.
