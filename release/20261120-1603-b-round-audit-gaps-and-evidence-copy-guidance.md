  - 뷰포트 명령: `browser.md`와 critique B 안내에 `agent-browser set viewport 390 844`(너비와 높이를 따로 넘김)와 `innerWidth` 확인을 넣는다

  - 프로젝트 밖 증거 파일을 거절할 때 보여 주는 복사 명령은 원본과 복사본을 절대 경로로 적는다. 셸이 어느 폴더에 있어도 같은 파일을 복사한다
  - `cp --`를 써서 `-`로 시작하는 경로를 옵션으로 읽지 않게 한다
  - `--file` 값은 러너가 루트 기준으로 푸는 `tasks/evidence/row-<행>.txt`를 그대로 쓴다
