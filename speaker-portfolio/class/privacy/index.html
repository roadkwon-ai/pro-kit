개인정보 안내

데모 동작 안내 · 서버 기능 연결 시 실제 처리 내용에 맞춰 교체해 주세요

데모 화면의 입력 처리 방식을 설명하는 샘플이에요. 실제 서비스의 개인정보처리방침을 대신하지 않아요.

1. 화면에서 입력하는 정보

화면입력 항목현재 처리
문의이름·이메일·연락처·내용페이지 메모리에서만 처리
신청 데모이름·이메일·연락처·과정 선택페이지 메모리에서만 처리
결제 데모화면 선택과 동의 상태실제 결제수단 수집·전송 없음

문의·신청 화면에 이름·이메일·전화번호·문의 내용을 입력할 수 있어요. 입력은 현재 페이지 메모리에서만 다루며 이 데모가 서버나 운영자에게 전송하지 않아요. 예시 정보로 체험해 주세요.

2. 입력을 사용하는 목적

  • 필수 항목과 형식을 확인하고 화면의 신청·문의 흐름을 보여 주는 데 사용해요. 복사 버튼을 누르면 확인한 내용을 내 기기의 클립보드에 넣어요. 복사 기능은 이메일 전송이나 접수가 아니에요.

3. 입력의 저장 범위

  • 연락처와 문의 내용은 브라우저 저장소에 저장하지 않아요. 페이지를 떠나거나 새로고침한 뒤 입력이 유지된다고 약속하지 않아요. 브라우저의 자동완성이나 기기의 클립보드 기록은 해당 환경의 설정에 따라 달라질 수 있어요.

4. 화면 설정 저장

언어와 테마 선택만 브라우저에 기억해 다음 방문에 적용해요. 이름·이메일·전화번호·문의 내용을 이 설정과 함께 저장하지 않아요. 브라우저 저장이 차단된 환경에서는 설정 기억이 제한될 수 있어요.

5. 외부 서비스 연결

연결 항목현재 상태
결제대행실제 연결 없음
입력 저장 서버연결 없음
이메일 전달연결 없음

기본 영상·도서 판매 주소는 비어 있는 예시이며 실제 재생·판매 서비스로 연결하지 않아요. 운영자가 외부 주소나 서버 기능을 등록하면 연결 대상과 실제 데이터 처리 방식을 다시 확인해야 해요.

결제 데모는 실제 결제대행사와 통신하지 않아요. 카드 정보나 실제 결제수단을 수집하지 않으며 주문·결제 식별자를 발급하지 않아요.

6. 입력 수정과 화면 나가기

입력 중에는 각 항목을 직접 수정하거나 지울 수 있어요. 데모에는 저장된 회원 정보나 운영자에게 열람·삭제를 요청할 접수 창구가 없어요. 실제 서비스로 바꿀 때는 실제 처리 범위에 맞는 안내를 준비해 주세요.

7. 복사한 내용

클립보드에 복사한 내용은 방문자의 기기에서 관리해요. 다른 앱에 붙여 넣거나 전송하는 행동은 이 데모의 복사 동작과 별개예요. 민감한 정보 대신 예시 문장으로 확인해 주세요.

8. 운영 기능을 연결할 때

서버 저장·메일 발송·로그인·실제 결제를 추가하면 수집 항목·이용 목적·저장 위치·보유 방식과 외부 제공 여부를 실제 구현에 맞춰 확인해요. 현재 샘플의 ‘전송하지 않아요’ 문구를 그대로 사용하지 않아요.

9. 운영 문의 정보

  • [운영자 이름]과 [개인정보 관련 문의 채널]을 실제 정보로 작성할 자리예요. 원본 사이트 운영자의 이름·주소·연락처를 이 프리셋의 담당자 정보로 사용하지 않아요.

10. 안내 변경

데이터 처리 동작이 바뀌면 화면과 안내를 함께 갱신해요. 실제 적용일과 공지 방식은 서비스 운영 내용에 맞춰 별도로 작성해 주세요. 이 샘플에는 실서비스 시행일이 정해져 있지 않아요.
