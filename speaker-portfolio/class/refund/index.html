환불 안내

샘플 문서 · 실제 환불 기준과 접수 방법은 운영 전에 작성해 주세요

환불 안내 화면의 샘플이에요. 실제 결제나 환불을 처리하지 않으며, 아래 문구는 판매 상품의 환불 조건이 아니에요.

1. 과정별 금액 구성

과정 예시금액구성
STANDARD[운영 전 확정][실제 제공 항목 작성]
PLUS[운영 전 확정][실제 제공 항목 작성]
PREMIUM[운영 전 확정][실제 제공 항목 작성]

클래스 화면의 과정과 가격은 예시예요. 실제 판매 시에는 수업·코칭 등 제공 항목과 금액 구성을 확정하고 이 영역에 안내해요. 현재 데모 금액으로 환불액을 계산하지 않아요.

2. 시작 전 취소

실제 과정 시작 전 취소 요청을 어디로 받고 어떻게 안내할지 작성할 자리예요. 이 데모에는 주문이 생성되지 않으므로 취소 요청이 접수되거나 알림이 발송되지 않아요.

3. 시작 후 취소

확인할 항목작성할 안내
수업 시작 여부[실제 일정 확인 방법]
진행한 수업[제공 내역 확인 방법]
남은 수업[잔여 항목 확인 방법]
개별 코칭[실제 코칭 처리 기준]

실제 서비스에서는 진행한 수업과 남은 제공 항목을 어떻게 확인하는지 설명해요. 적용할 환불 기준과 계산 방법은 운영자가 실제 상품에 맞춰 준비해야 해요.

라이브 수업과 개별 코칭의 처리 방식이 다르다면 항목별로 안내해요. 이 샘플에는 환불 비율·공제 금액·처리 기한을 정해 두지 않았어요.

4. 일정 변경과 운영 중단

  1. 운영 일정이 달라졌을 때 안내할 채널과 방문자가 선택할 수 있는 절차를 작성할 자리예요. 실제 수업 운영이 없는 데모이므로 변경·환불 요청을 실행하지 않아요.

5. 안내 내용 확인

실제 판매 페이지와 신청 화면, 약관, 환불 안내의 상품 설명과 조건을 서로 맞춰 주세요. 예시 가격이나 문구를 그대로 실서비스의 약속으로 사용하지 않아요.

6. 문의와 처리 방법

  1. [취소·환불 문의 채널]과 [요청 시 확인할 항목]을 실제 운영 방식으로 채울 자리예요. 이 화면에는 환불 접수 기능이나 연결된 결제대행사가 없어요.
  2. 문의 문장을 복사하는 기능은 내용 준비만 도와줘요. 복사했다고 운영자에게 전달되거나 환불 요청이 접수되는 것은 아니에요.

7. 운영 전 확인

  1. 실제 결제 기능을 연결하기 전에 상품·결제 처리·취소 흐름과 안내 문서가 일치하는지 확인해 주세요. 이 페이지는 확정된 환불 규정을 대신하지 않아요.
