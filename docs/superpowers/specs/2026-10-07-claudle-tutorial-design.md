상태: 사용자 결정(2026-10-07): Claude는 클론코딩 튜토리얼로 만든다, 이름은 Claudle, 화면은 Nextflix 확장처럼 "웹에 있는 거의 모든 화면"을 넣는다(시크릿 대화에서 메시지를 보내 본 보강 조사 반영). 나머지는 리서치 추천안이다. 사용자가 실행 계획 작성을 지시했다(2026-10-07). AI 연결은 Kilo AI Gateway 무료 모델, 하루 200회 한도와 "내일" 안내로 바꿨다(사용자 결정 2026-10-07, 6.5절).

## 1. 목표와 성공 기준

비개발자와 AI 개발 초보자가 pro-kit과 프리셋 팩만으로 Claude 같은 AI 대화 서비스를 만든다. 원래 서비스를 조사하지 않고, 이름 한 줄만 바꿔 자기 서비스로 만들 수 있다. **AI 키가 없어도 끝까지 간다**(모의 응답). 키를 넣으면 Kilo AI Gateway의 무료 모델로 실제 답한다(결제 없음, 6.5절).

- 프리셋 사이트(4장 결과)를 프리셋 팩만으로 만들 수 있다(팩 검증).
- 프리셋의 모든 링크와 버튼이 동작한다. 404나 "준비 중"이 없다. 만들지 않는 기능은 버튼째 뺀다.
- 튜토리얼 프롬프트에 색, 크기 같은 값이 없고 팩을 가리킨다.
- Claude·Anthropic 이름과 워드마크, 스파크 마크, 클레이 `#d97757`·`#c6613f`, Anthropic Serif/Sans/Mono, Claude의 문구와 손그림이 저장소, 팩, 프리셋 어디에도 없다. 모델 이름도 가상이다.
- 프롬프트가 pro-kit 절차(`AGENTS.md`, `prokit-ui`, `prokit-dev-cycle`)와 어긋나지 않는다. 5장부터는 끝까지 실행해 확인하지 않는다(Nextflix와 같음).

### 5.2 받을 원문
Refero Claude. Nextflix와 같은 함정이다: 원문은 앱(대화·사이드바)이 아니라 로그인 전 첫 화면 기준이라 "받은 뒤 고칠 것"이 꼭 필요하다. 주소가 열리지 않으면 Anthropic(`d469cba4…`)을 받아 같은 고칠 것을 적용한다.

### 5.3 받은 뒤 고칠 것 (`design-notes.md`)
- **기준 화면**: 앱 화면 값으로 고친다(리서치 `03` 1~5절 실측). 라이트·다크 둘 다, 기본은 시스템 설정. 사이드바·대화 열·뷰어 치수, 사용자 말풍선만 있고 답은 말풍선 없음, 입력창 모서리 14, 모션 60/120/200/300/450ms와 답의 어절 페이드 0.4s. 소개·요금제·로그인은 공개 사이트 값으로 두되 같은 색·서체 체계를 쓴다.
- **브랜드 대체**: 강조색 벽돌 주황 `#BF4F2C`(흰 글자 4.81:1, 다크 강조 글자 `#E0794A`), 중립은 같은 따뜻한 계열의 다른 값(리서치 `06` 5.2절). 서체 Source Serif 4(영문·숫자·인사말·로고) + Pretendard(한글·본문) + JetBrains Mono(코드), 모두 OFL. 로고는 서비스 이름 글자, 인사말 심볼은 자체 단순 SVG. 아이콘 lucide. 토큰 이름에 남은 "Claude", "Anthropic"을 바꾼다.
- **원문 정리와 확인**: Nextflix 5.3절과 같다(frontmatter를 표 값으로, `Similar Brands`·`Quick Start` 삭제, lint 결과를 `design-notes.md`에 기록).

### 6.1 `features.md` 규칙
리서치 `04` "넣을 만한 규칙 후보"와 `05` 7절 설계 결정을 옮긴다. 요점:
- **대화(5·6장)**: 사용자별. 목록은 고정됨 구역(고정한 시각 순) + 최근 구역(마지막 메시지 순, 50개씩). 제목이 없으면 "새 대화", 첫 메시지 앞 40자를 임시 제목으로, 사용자가 바꾼 제목은 덮어쓰지 않는다. 삭제는 확인 뒤 즉시, 메시지까지 함께.
- **AI 답(5·7장)**: 키 유무는 `KILO_API_KEY`로 먼저 고른다. 키가 있으면 Kilo 무료 모델(6.5절), 없으면 미리 써 둔 답을 키워드 규칙으로 골라 글자 단위로 흘리고 "모의 응답" 표시. 중지하면 지금까지 나온 글을 저장한다(완료 집계를 기다리지 않는다). 메시지 20,000자, 모델에 보내는 기록은 최근 40개.
- **사용량 한도(7장)**: 키가 있을 때만. 서비스 전체에서 하루 답 200회(한국 시각 0시에 다시 센다. 키 하나를 모두 나눠 쓰므로 사용자별이 아니라 전체). 오늘 실제 모델이 만든 답 수를 DB에서 세어 200회가 차면 모델을 부르지 않는다. Kilo가 429를 주어도 같다. 두 경우 모두 답 자리에 안내를 보인다: "오늘 쓸 수 있는 사용량을 다 썼어요. 내일 다시 쓸 수 있어요." 이 안내는 메시지로 저장하지 않고 다시 시도 버튼도 두지 않는다.
- **검색(8장)**: 제목과 본문, 내 대화만, `pg_trgm`.
- **프로젝트(9장)**: 5개까지, 지침 8,000자, 텍스트 지식 파일(파일당 200KB, 20개). 지침과 파일을 그 프로젝트 대화의 시스템 지침에 붙인다.
- **아티팩트(10장)**: 답의 html·svg 코드 블록에 "미리 보기" → 오른쪽 패널 iframe. `sandbox="allow-scripts"`만, `allow-same-origin`은 쓰지 않는다. 맨 앞에 CSP meta로 외부 요청을 막는다.

### 6.5 AI 연결: Kilo AI Gateway 무료 모델 (사용자 결정 2026-10-07)
처음 설계의 Vercel AI Gateway(`AI_GATEWAY_API_KEY`)를 쓰지 않는다. 리서치 `05`의 AI Gateway 부분도 따르지 않는다.

| 항목 | 값 | 확인 |
|---|---|---|
| 주소 | `https://api.kilo.ai/api/gateway`(OpenAI 호환 chat completions) | 문서 `kilo.ai/docs/gateway/api-reference` |
| 키 | `.env`의 `KILO_API_KEY`, `Authorization: Bearer` | 같은 문서 |
| AI SDK | `@ai-sdk/openai`의 `createOpenAI({ baseURL, apiKey })`, 모델은 `.chat("kilo-auto/free")`(Responses API가 아니다) | `ai` 7.0.130 + `@ai-sdk/openai` 4.0.86으로 스트리밍 한국어 답 확인(첫 글자 약 4초) |
| 무료 모델 | `kilo-auto/free`(무료 모델 중에서 Kilo가 고른다). `:free`가 붙은 모델도 무료 | `GET /models`(인증 없음)에 무료 22개 |
| 한도 넘음 | HTTP 429, `{ "error": { "message": "Rate limit exceeded for free models. Please try again later.", "code": 429 } }`. 한도 헤더는 없다 | AI SDK에서 `APICallError`(`statusCode` 429). `toUIMessageStream({ onError })`에서 안내로 바꾸는 것을 가짜 429 서버로 확인 |

모델 메뉴의 `Quick`이 이 무료 모델이다. `Balanced`·`Deep`은 메뉴에 두되 잠그고 누르면 `/upgrade`로 간다(유료 모델을 쓰지 않는다). 키 값은 출력, 커밋, 정적 내보내기 어디에도 남기지 않는다.

### 6.6 공개 프리셋의 실제 AI: 릴레이 서버 (사용자 결정 2026-10-07)
GitHub Pages는 정적이라 키를 둘 수 없고, Kilo는 브라우저 호출을 받지 않는다(CORS 헤더 없음). 그래서 키를 가진 중계 서버 `claudle-relay`(`../pro-kit-samples/ws/claudle-relay`, Vercel 함수 하나)를 둔다. 프리셋은 `NEXT_PUBLIC_RELAY_URL`이 있으면 `useChat`의 `DefaultChatTransport`로 이 서버를 부르고, 없으면 지금처럼 모의 응답을 쓴다.

- 릴레이 순서: Gemini 3.8 Flash → Cloudflare Qwen3.8 27B → Gemini 3.5·2.5·3.1 Flash-Lite → Z.AI GLM-4.7-Flash → Kilo `kilo-auto/free` → Requesty Ling 3.1 Flash → Vercel AI Gateway Ling 3.1 Flash Free·Laguna S 2.1 Free. 앞 공급자가 한도·과부하·10초 무응답이면 다음으로 넘긴다. 모두 한도면 "내일" 안내, 아니면 "잠시 뒤" 안내.
- 무료 범위만 쓴다: 가격표 값 0(Kilo·Requesty·Vercel), Workers 유료 구독 없음(Cloudflare)을 1시간마다 확인한다. Gemini는 결제를 켜지 않은 프로젝트 키만 쓴다.
- 막는 것: 출처(`roadkwonai.github.io`, localhost), IP당 10분 30회, 메시지 40개·2만 자.
- 튜토리얼 7장은 그대로 Kilo 키 하나로 쓴다. 릴레이는 12장 팁으로 소개한다.
- 릴레이와 프리셋 배포는 모든 작업을 마치고 보고한 뒤 사용자가 올리라고 할 때만 한다.

## 9. 확인하지 못한 것과 위험

- 직접 보지 못한 화면(실제 스트리밍, 생각 중 표시, 오류·재시도, 아티팩트 코드 탭, 확인 창, 공개 페이지 390 실측)은 [추정]으로 두고 프롬프트에 단정해 쓰지 않는다.
- Claude 화면은 자주 바뀐다. 조사일(2026-10-07)을 팩에 적는다. Refero 원문도 다시 추출되거나 내려갈 수 있어 id와 추출일, 대안 주소를 둔다.
- AI SDK 7판, oRPC 1.15, Streamdown 2.7처럼 판이 빨리 바뀐다. 리서치 `05`의 확인 판을 `features.md`에 적고 5·7장 "막히면"에 판 차이를 안내한다.
- 이름: Claudle은 웹 검색과 `.com`·`.ai`·`.app`에서 같은 이름의 AI 서비스를 찾지 못했다(2026-10-07). 앱 스토어, GitHub, npm은 팩을 만들 때 한 번 더 본다. 화면과 첫 쪽에 "Claude와 관계없는 연습용"을 둔다.
- 독자 비용: Kilo 무료 모델이라 $0이다. Kilo 가입은 무료이고 Kilo Pass(유료 크레딧 구독)는 필요 없다. 공개 배포에서는 하루 200회를 방문자 모두가 나눠 쓴다.
- Kilo 무료 모델: `kilo-auto/free`가 고르는 모델은 서버 쪽에서 바뀐다(2026-10-07 시험에서는 `stepfun/step-3.7-flash`). 무료 공급자는 대화를 기록하고 서비스 개선에 쓸 수 있어, 화면과 7장에 개인 정보를 넣지 말라는 안내를 둔다. 한도는 Kilo 문서에 "익명 사용자 IP당 시간당 200회"로 적혀 있다. 사용자가 정한 하루 200회를 앱이 따로 세서 "내일" 안내가 맞게 한다. 문서의 값이 바뀌면 7장 "막히면"을 고친다.
