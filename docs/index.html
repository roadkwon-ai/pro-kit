문서 시작하기핵심 개념

핵심 3가지

  • 하네스

    에이전트가 정해진 순서와 검사를 지키며 일하게 만드는 규칙, 스킬, 자동 검사의 묶음이에요. 하네스 엔지니어링

  • 전용 스킬

    prokit-* 스킬 8개가 분야마다 일하는 법을 알려 주고, 그 분야의 공식 스킬을 불러 써요. prokit 스킬 8개

  • 디자인부터 배포까지

    스타일 추천과 DESIGN.md로 디자인을 정하고, HTML 내보내기나 Vercel 배포까지 이어져요. UI/UX 흐름
