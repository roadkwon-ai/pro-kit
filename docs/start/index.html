시작하기

한눈에

프로킷이 무엇인지 알고, 필요한 것을 준비해 첫 프로젝트를 만들어요. 화면만 빠르게 만들 수도 있고, 로그인과 DB까지 갖춘 서비스로 시작할 수도 있어요.

  1. 01프로킷이란AI 에이전트에 설치하는 개발 키트, 그냥 맡길 때와 무엇이 다른지읽기
  2. 02이런 분께 추천해요프로킷을 추천하는 분과 맞지 않을 때, 프로킷 없이와 프로킷으로 비교, 실제 사례읽기
  3. 03준비물Node 22.20, pnpm, git, 컨테이너 엔진, Supabase CLI, Windows는 WSL2읽기
  4. 04지원하는 에이전트Claude Code, Codex, Antigravity, Grok Build가 읽는 파일, 이미지 도구, 여는 명령읽기
  5. 05빠른 시작: 화면만 만들기DB 없이 프롬프트 하나로 모든 화면과 HTML 내보내기까지읽기
  6. 06빠른 시작: 서비스 만들기템플릿 고르기부터 로컬 DB, 첫 마이그레이션, 커밋까지읽기
  7. 07만든 뒤 개발하기새 세션에서 평소 말로 요청하기, 예시 프롬프트읽기
