# 줄 꼴: `글의 앞부분 :: 이유`. 앞부분은 공백을 하나로 편 글이고 과정 이름(nextflix, claudle)은 ◇, 그 뒤 조사는 한 꼴(를·는·가·와·로·라·예요)이다.
# 앞부분은 바뀔 수 있는 값을 빼고 짧게 쓴다. `@문서 파일 파일 :: 이유`는 그 파일들을 한 문서로 센다(그 사이의 반복만 허용하고 다른 문서와의 반복은 여전히 잡는다).
| `pnpm dev-cycle case` | :: handbook 명령 모음(handbook/reference/commands.md)의 dev-cycle 표는 템플릿 README 명령 표(명령의 정본)를 handbook 독자에게 맞게 줄여 다시 쓴 표라 행마다 설명이 다르고, 설명이 짧은 이 행만 같다. 한 행만 묶음으로 떼면 두 표의 다른 행과 꼴이 갈려 공통화하지 않는다. handbook 표의 명령과 플래그가 README 표에 있는지는 doc-values.test.mjs가 본다
