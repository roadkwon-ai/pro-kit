`[{{name}}]`{{neun}} 프로젝트 폴더 이름이에요. 폴더 이름을 바꿨다면 이 장의 `[{{name}}]`도 모두 내 폴더 이름으로 바꾸세요.

```prompt
GitHub에 [{{name}}] 비공개 저장소를 만들어서 이 프로젝트와 origin으로 연결하고, 지금까지 커밋을 올려줘.
```

비공개 저장소의 코드는 나만 볼 수 있어요. 연결한 뒤부터는 [라운드](../reference/glossary.md#만들기)({{v:gloss.round}})가 끝날 때마다 커밋이 GitHub에도 올라가요.

**이렇게 되면 성공**
- GitHub의 내 저장소 목록에 `{{name}}` 저장소가 생기고, 지금까지 한 커밋이 보여요.
- 저장소 이름 옆에 Private 표시가 있어요.
