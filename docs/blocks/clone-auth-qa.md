이 장부터는 프로젝트 폴더에서 연 에이전트가 기능마다 라운드 하나로 진행해요. 라운드 끝에는 늘 직접 써 보고 확인해 달라고 해요. 선택지 창이 뜨면 아래 답과 같은 선택지를 고르고, 없으면 직접 입력하는 칸에 붙여 넣으세요([질문에 답하는 법](../reference/claude-code-and-codex.md#질문에-답하는-법)).

| 질문 | 답 |
|---|---|
| 외부 스킬의 새 판이 있다며 업데이트할지(하루에 한 번까지) | `나중에`. `지금 업데이트`를 고르면 업데이트 라운드를 먼저 따로 열어 확인과 커밋까지 마친 뒤 이 장으로 돌아와요. 장을 마친 뒤 `스킬 업데이트해줘`라고 보내면 그때 따로 해요 |
| 스펙을 정하기 전에 고를 것 | 모르겠으면 `추천대로 해줘` |
