# 시작하기

> 한눈에: 프로킷이 무엇인지 알고, 필요한 것을 준비해 첫 프로젝트를 만들어요. **새 프로젝트는 만들기 전에 PRD(만들 서비스를 적은 기획 문서)부터 정해요.** 프로킷이 PRD로 스킬 구성을 추천하고 개발 환경을 만들기 때문이에요. 화면만 빠르게 만들 수도 <!-- edition:pro -->있고, 로그인과 DB까지 갖춘 서비스로 시작할 수도 있어요. 이미 진행하던 프로젝트에도 분석부터 시작해 들일 수 있어요<!-- /edition --><!-- edition:ui 있어요 -->.
