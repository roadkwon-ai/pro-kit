# 슬라이드랩
https://prokit-web.vercel.app/tutorials/samples/slidelab/

AI·PPT 교육을 소개하는 한 페이지 프리셋이에요. 과정과 교육 시간을 고르면 문의에 반영되고, 템플릿과 학습 노트를 같은 페이지에서 살펴볼 수 있어요. 문의는 입력 검사 뒤 예시 완료 상태를 보여 주며 실제로 전송하지 않아요.

![슬라이드랩 제작 검수에서 촬영한 첫 화면](https://prokit-web.vercel.app/images/tutorials/samples/slidelab-home-desktop.webp)

[프리셋 사이트 열기](https://roadkwon-ai.github.io/pro-kit/slidelab/) · [프로킷 사이트에서 보기](https://prokit.highvalue.kr/work/slidelab/)

| 항목 | 내용 |
|---|---|
| 페이지 | 1개, 소개·고객사 예시·현장·커리큘럼·후기·프로그램·템플릿·콘텐츠·문의까지 같은 페이지에서 이어져요 |
| 디자인 참고 | [pptpro.kr](https://pptpro.kr/)의 구조·서체·색상·스크롤 효과를 관측했어요. 인물·고객사·실적·사진은 복제하지 않았어요 |
| 대표 색 | 다크 라임, `#c8ff00` |
| 서체 | Outfit, Noto Sans KR. 자체 호스팅 파일과 OFL 이용 조건을 포함해요 |
| 생성 이미지 | 13개, 인물·강의·제품·학습 장면은 가상 예시예요 |
| 설정 | 시스템·라이트·다크와 한국어·영어 전환을 제공해요. 프로킷 미리보기에서는 기존 공통 설정으로 서체·팔레트를 비교해요 |
| 검사 | 현재 내보낸 화면에서 링크·버튼 40번, 없는 페이지·콘솔 오류·반응 없는 버튼은 없었어요 |

## 프리셋 팩으로 만들어 보기

작업 폴더 `~/projects`에서 연 에이전트에 이 프롬프트를 보내면 슬라이드랩 프리셋과 같은 서비스를 만들어요. [프리셋 팩](https://github.com/roadkwon-ai/pro-kit-packs/releases/tag/pack-slidelab)의 화면 구성, 디자인, 예시 데이터, 그림을 그대로 써서 AI 그림을 새로 그리지 않아요. `[ ]` 안의 이름을 바꿔 같은 구성의 서비스를 만들어요. 팩을 써도 AI가 만들기 때문에 100% 똑같지는 않을 수 있어요.

```prompt
https://github.com/roadkwon-ai/pro-kit 을 이 폴더에 받고, 그 안의 AGENTS.md대로 화면만 만들 프로젝트를 pro-kit 옆에 [slidelab] 폴더로 만들어줘.
DB는 쓰지 않아. 없는 준비물은 설치해줘.
옆 폴더 pro-kit의 packs/slidelab에 프리셋 팩을 받아줘.
그 팩대로 슬라이드랩 프리셋과 똑같은 서비스를 만들 거야. 이름은 [슬라이드랩].
팩의 README.md 순서대로 하고, 팩은 고치지 마. 이름을 바꿨으면 팩의 이름 대신 내가 정한 이름을 써.
디자인, 화면 구성, 그림은 팩에 있는 것을 써. 스타일 추천, 시안, 새 그림은 만들지 마.
모든 페이지의 기본 디자인은 팩의 스크린샷과 같게 만들어줘.
시스템·라이트·다크 모드 전환과 한국어·영어 전환을 모든 페이지의 기본 기능으로 넣어줘. 화면 문구는 같은 키를 가진 두 언어의 번역 사전에서 관리하고, 전환해도 현재 페이지와 입력을 유지해줘. 개발 화면과 HTML로 내보낸 결과에서 모든 페이지의 전환과 상태 유지를 실제로 확인해줘.
다 만들면 HTML 파일로 내보내줘.
```

> [!IMPORTANT]
> **프롬프트만 보내면 에이전트가 이 프리셋 팩을 자동으로 받아 설치해요. 따로 받지 않아도 돼요.**
>
> 직접 받으려면 [slidelab-pack.zip](https://github.com/roadkwon-ai/pro-kit-packs/releases/download/pack-slidelab/slidelab-pack.zip)(34.9MB, [릴리스](https://github.com/roadkwon-ai/pro-kit-packs/releases/tag/pack-slidelab))을 받고, 프롬프트 끝에 `프리셋 팩 zip은 [~/Downloads/slidelab-pack.zip]에 받아 뒀어.` 한 줄을 더하세요. 에이전트가 그 zip이 최신 판인지 확인하고, 옛 판이면 새로 받아요.

에이전트를 아직 열지 않았으면 [1. 작업 폴더에서 에이전트 열기](https://prokit-web.vercel.app/tutorials/samples/#1-작업-폴더에서-에이전트-열기)부터 하세요. 프롬프트를 보낸 다음에는 [3. 알려 준 한 줄로 이어 가기](https://prokit-web.vercel.app/tutorials/samples/#3-알려-준-한-줄로-이어-가기)와 [4. 답하며 요청을 자세히 채우기](https://prokit-web.vercel.app/tutorials/samples/#4-답하며-요청을-자세히-채우기)를 따라가면 돼요.

## 프리셋 팩으로 나만의 서비스 만들기

슬라이드랩의 [프리셋 팩](https://github.com/roadkwon-ai/pro-kit-packs/releases/tag/pack-slidelab)을 바탕으로 이름, 색, 페이지, 주제를 바꿔 나만의 서비스를 만들어요. 화면 구성과 디자인이 정해져 있어서 처음부터 만들 때보다 빠르고, 맞지 않는 그림만 같은 화풍으로 다시 그려요.

```prompt
https://github.com/roadkwon-ai/pro-kit 을 이 폴더에 받고, 그 안의 AGENTS.md대로 화면만 만들 프로젝트를 pro-kit 옆에 [workshop] 폴더로 만들어줘.
DB는 쓰지 않아. 없는 준비물은 설치해줘.
옆 폴더 pro-kit의 packs/slidelab에 프리셋 팩을 받아줘.
그 팩을 바탕으로 나만의 서비스를 만들 거야. 이름은 [우리 워크숍].
바꿀 것: [주제는 발표 교육, 대표 색은 짙은 파랑]
팩의 README.md와 CUSTOMIZE.md를 보고, 바꾸는 것에 맞춰 다시 할 일만 해줘. 다시 그릴 그림은 팩의 prompts.json을 고쳐 같은 화풍으로 그려줘.
팩은 고치지 말고, 바꾸지 않는 것은 팩대로 해.
시스템·라이트·다크 모드 전환과 한국어·영어 전환을 모든 페이지의 기본 기능으로 넣어줘. 화면 문구는 같은 키를 가진 두 언어의 번역 사전에서 관리하고, 전환해도 현재 페이지와 입력을 유지해줘. 개발 화면과 HTML로 내보낸 결과에서 모든 페이지의 전환과 상태 유지를 실제로 확인해줘.
다 만들면 HTML 파일로 내보내줘.
```

`바꿀 것`에는 이렇게 적어요.
- 색이나 서체: `대표 색은 짙은 파랑, 제목 서체는 더 둥글게`
- 페이지: `[페이지 이름] 페이지는 빼줘` 또는 `[페이지 이름] 페이지를 더해줘`
- 주제: `주제는 발표 교육`

무엇을 바꾸면 무엇을 다시 하는지는 팩의 `CUSTOMIZE.md`에 있어요. **그림을 다시 그리려면 이미지를 그릴 수 있는 에이전트가 필요해요**([이미지 그리기](https://prokit-web.vercel.app/tutorials/reference/costs-and-keys/#이미지-그리기)). 그릴 수 없으면 원래 그림을 그대로 써요.

팩 zip을 미리 받아 두었다면 [프리셋 팩으로 만들어 보기](https://prokit-web.vercel.app/tutorials/samples/slidelab/#프리셋-팩으로-만들어-보기)처럼 이 프롬프트 끝에도 zip 경로 한 줄을 더하세요.

## 이 컨셉으로 처음부터 만들기

작업 폴더 `~/projects`에서 연 에이전트에 이 프롬프트를 그대로 보내면 **바로** 시작돼요. [가장 쉬운 방법](https://prokit-web.vercel.app/tutorials/samples/#가장-쉬운-방법)의 프롬프트와 같고, `[ ]` 안만 이 프리셋의 폴더 이름과 컨셉이에요. 원하는 대로 바꿔도 돼요.

```prompt
https://github.com/roadkwon-ai/pro-kit 을 이 폴더에 받고, 그 안의 AGENTS.md대로 화면만 만들 프로젝트를 pro-kit 옆에 [slidelab] 폴더로 만들어줘.
DB는 쓰지 않아. 없는 준비물은 설치해줘.
[AI·PPT 교육 과정을 소개하고 과정과 교육 시간을 고른 뒤 예시 문의를 남기는 한 페이지 사이트]를 만들고 싶어.
필요한 화면을 모두 예시 데이터로 만들어줘. 로그인이나 저장 같은 기능은 빼고 화면만 만들어.
시스템·라이트·다크 모드 전환과 한국어·영어 전환을 모든 페이지의 기본 기능으로 넣어줘. 화면 문구는 같은 키를 가진 두 언어의 번역 사전에서 관리하고, 전환해도 현재 페이지와 입력을 유지해줘. 개발 화면과 HTML로 내보낸 결과에서 모든 페이지의 전환과 상태 유지를 실제로 확인해줘.
디자인 스타일은 서비스에 어울리는 걸로 추천해주고, 다 만들면 HTML 파일로 내보내줘.
```

**같은 컨셉이라도 이름, 스타일, 화면은 매번 다르게 나와요.** 프리셋에 가깝게 만들려면 [프리셋 팩으로 만들어 보기](https://prokit-web.vercel.app/tutorials/samples/slidelab/#프리셋-팩으로-만들어-보기)를 쓰세요.

에이전트를 아직 열지 않았으면 [1. 작업 폴더에서 에이전트 열기](https://prokit-web.vercel.app/tutorials/samples/#1-작업-폴더에서-에이전트-열기)부터 하세요. 프롬프트를 보낸 다음에는 [3. 알려 준 한 줄로 이어 가기](https://prokit-web.vercel.app/tutorials/samples/#3-알려-준-한-줄로-이어-가기)와 [4. 답하며 요청을 자세히 채우기](https://prokit-web.vercel.app/tutorials/samples/#4-답하며-요청을-자세히-채우기)를 따라가면 돼요.

## 실제로 보완한 부분

넓은 화면의 중앙 정렬, 프로필과 다음 영역의 스크롤 겹침, 사진 누락과 세로 콘텐츠 잘림을 고쳤어요. 현재판에는 두 언어의 문구, 밝고 어두운 의미 색상, 입력을 유지하는 전환, 폰트 이용 조건을 추가했어요. 자세한 내용은 [제작 검증 기록](https://github.com/roadkwon-ai/pro-kit/blob/main/docs/reports/2026-10-10-slidelab-reference-fidelity/README.md)에 있어요.

## 실제 서비스로 만들 때

문의 전달 서비스와 개인정보 처리 방식을 정해야 해요. 이 프리셋의 고객사·후기·강사와 현장 이미지는 예시이므로 실제 정보로 교체하고, 사용할 권리를 확인해요. 로그인·결제·DB는 현재 프리셋에 포함하지 않았어요.

## 시간과 비용

프리셋 팩으로 다시 만들 때는 한 번에 완성하면 약 36분\~1시간 10분(여러 번 고쳐 달라고 하면 약 1시간 50분까지)이고, 토큰은 최소 약 73.4만(캐시 포함 약 3671.3만)으로 예상해요. 처음부터 화면을 만들 때는 한 번에 완성하면 약 1시간 5분\~2시간 10분(여러 번 고쳐 달라고 하면 약 3시간 15분까지)과 최소 약 154.7만 토큰으로 예상해요.

시간은 공통 단계별 계획의 합이고, 토큰은 같은 정책의 기준 단위에서 환산한 예상값이에요. 검사 예상은 이 프리셋의 화면 범위를 기준으로 정했어요. [예상 계산 근거](https://github.com/roadkwon-ai/pro-kit/blob/main/docs/reports/2026-10-13-preset-measurements.json)를 확인해요.

실제 제작 기록이나 현재 제공자의 청구 요금을 뜻하지 않으며, API·DB·실결제 개발은 포함하지 않았어요. 고쳐 달라는 횟수와 사용하는 모델에 따라 늘어날 수 있어요. [시간과 비용 읽는 법](https://prokit-web.vercel.app/tutorials/reference/costs-and-keys/#시간과-비용-읽는-법)을 참고해요.

이전 제작 중 일부 구간의 기록은 보존하지만 전체 제작량으로 합치지 않았어요. [기록의 범위](https://github.com/roadkwon-ai/pro-kit/blob/main/docs/reports/2026-10-11-preset-skills/README.md)와 팩 재현 예상을 구분해요.

디자인 평가는 닐슨의 열 가지 기준으로 27점이며, [기준별 점수와 감점 이유](https://prokit.highvalue.kr/process/?preset=slidelab#step-5)를 함께 확인해요.
