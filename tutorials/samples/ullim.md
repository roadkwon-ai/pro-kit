# 울림
https://prokit-web.vercel.app/tutorials/samples/ullim/

AI 내레이션 스튜디오예요. 유튜브나 팟캐스트를 혼자 만드는 사람이 대본을 붙여 넣으면 한국어 내레이션을 만들어 주고, 문장마다 억양과 쉼, 감정을 고쳐서 방송에 쓸 수 있는 음성으로 다듬을 수 있게 해 줘요. 첫 화면 문구는 "한 줄의 대본도, 마음을 울리는 목소리로"예요.

## 프리셋 팩으로 만들어 보기

작업 폴더 `~/projects`에서 연 에이전트에 이 프롬프트를 보내면 울림 프리셋과 같은 서비스를 만들어요. [프리셋 팩](https://github.com/roadkwon-ai/pro-kit-packs/releases/tag/pack-ullim)의 화면 구성, 디자인, 예시 데이터, 그림을 그대로 써서 AI 그림을 새로 그리지 않아요. `[ ]` 안의 이름만 바꾸면 이름만 다른 서비스가 나와요. 팩을 써도 AI가 만들기 때문에 100% 똑같지는 않을 수 있어요.

```prompt
https://github.com/roadkwon-ai/pro-kit 을 이 폴더에 받고, 그 안의 AGENTS.md대로 화면만 만들 프로젝트를 pro-kit 옆에 [ullim] 폴더로 만들어줘.
DB는 쓰지 않아. 없는 준비물은 설치해줘.
옆 폴더 pro-kit의 packs/ullim에 프리셋 팩을 받아줘.
그 팩대로 울림 프리셋과 똑같은 서비스를 만들 거야. 이름은 [울림].
팩의 README.md 순서대로 하고, 팩은 고치지 마. 이름을 바꿨으면 팩의 이름 대신 내가 정한 이름을 써.
디자인, 화면 구성, 그림은 팩에 있는 것을 써. 스타일 추천, 시안, 새 그림은 만들지 마.
모든 페이지를 팩의 스크린샷과 같게 만들고, 다 만들면 HTML 파일로 내보내줘.
```

> [!IMPORTANT]
> **프롬프트만 보내면 에이전트가 이 프리셋 팩을 자동으로 받아 설치해요. 따로 받지 않아도 돼요.**
>
> 직접 받으려면 [ullim-pack.zip](https://github.com/roadkwon-ai/pro-kit-packs/releases/download/pack-ullim/ullim-pack.zip)(11.3MB, [릴리스](https://github.com/roadkwon-ai/pro-kit-packs/releases/tag/pack-ullim))을 받고, 프롬프트 끝에 `프리셋 팩 zip은 [~/Downloads/ullim-pack.zip]에 받아 뒀어.` 한 줄을 더하세요. 에이전트가 그 zip이 최신 판인지 확인하고, 옛 판이면 새로 받아요.

에이전트를 아직 열지 않았으면 [1. 작업 폴더에서 에이전트 열기](https://prokit-web.vercel.app/tutorials/samples/#1-작업-폴더에서-에이전트-열기)부터 하세요. 프롬프트를 보낸 다음에는 [3. 알려 준 한 줄로 이어 가기](https://prokit-web.vercel.app/tutorials/samples/#3-알려-준-한-줄로-이어-가기)와 [4. 답하며 요청을 자세히 채우기](https://prokit-web.vercel.app/tutorials/samples/#4-답하며-요청을-자세히-채우기)를 따라가면 돼요.

## 프리셋 팩으로 나만의 서비스 만들기

울림의 [프리셋 팩](https://github.com/roadkwon-ai/pro-kit-packs/releases/tag/pack-ullim)을 바탕으로 이름, 색, 페이지, 주제를 바꿔 나만의 서비스를 만들어요. 화면 구성과 디자인이 정해져 있어서 처음부터 만들 때보다 빠르고, 맞지 않는 그림만 같은 화풍으로 다시 그려요.

```prompt
https://github.com/roadkwon-ai/pro-kit 을 이 폴더에 받고, 그 안의 AGENTS.md대로 화면만 만들 프로젝트를 pro-kit 옆에 [storyvoice] 폴더로 만들어줘.
DB는 쓰지 않아. 없는 준비물은 설치해줘.
옆 폴더 pro-kit의 packs/ullim에 프리셋 팩을 받아줘.
그 팩을 바탕으로 나만의 서비스를 만들 거야. 이름은 [이야기 소리].
바꿀 것: [주제는 어린이 동화 낭독, 제목 서체는 더 둥글게]
팩의 README.md와 CUSTOMIZE.md를 보고, 바꾸는 것에 맞춰 다시 할 일만 해줘. 다시 그릴 그림은 팩의 prompts.json을 고쳐 같은 화풍으로 그려줘.
팩은 고치지 말고, 바꾸지 않는 것은 팩대로 해. 다 만들면 HTML 파일로 내보내줘.
```

`바꿀 것`에는 이렇게 적어요.
- 색이나 서체: `대표 색은 짙은 파랑, 제목 서체는 더 둥글게`
- 페이지: `[페이지 이름] 페이지는 빼줘` 또는 `[페이지 이름] 페이지를 더해줘`
- 주제: `주제는 어린이 동화 낭독`

무엇을 바꾸면 무엇을 다시 하는지는 팩의 `CUSTOMIZE.md`에 있어요. **그림을 다시 그리려면 이미지를 그릴 수 있는 에이전트가 필요해요**([이미지 그리기](https://prokit-web.vercel.app/tutorials/reference/costs-and-keys/#이미지-그리기)). 그릴 수 없으면 원래 그림을 그대로 써요.

팩 zip을 미리 받아 두었다면 [프리셋 팩으로 만들어 보기](https://prokit-web.vercel.app/tutorials/samples/ullim/#프리셋-팩으로-만들어-보기)처럼 이 프롬프트 끝에도 zip 경로 한 줄을 더하세요.

## 이 컨셉으로 처음부터 만들기

작업 폴더 `~/projects`에서 연 에이전트에 이 프롬프트를 그대로 보내면 **바로** 시작돼요. [가장 쉬운 방법](https://prokit-web.vercel.app/tutorials/samples/#가장-쉬운-방법)의 프롬프트와 같고, `[ ]` 안만 이 프리셋의 폴더 이름과 컨셉이에요. 원하는 대로 바꿔도 돼요.

```prompt
https://github.com/roadkwon-ai/pro-kit 을 이 폴더에 받고, 그 안의 AGENTS.md대로 화면만 만들 프로젝트를 pro-kit 옆에 [ullim] 폴더로 만들어줘.
DB는 쓰지 않아. 없는 준비물은 설치해줘.
[혼자 영상이나 팟캐스트를 만드는 사람이 대본을 붙여 넣으면 내레이션 음성을 만들어 주고, 문장마다 억양과 쉼을 고칠 수 있게 해 주는 서비스]를 만들고 싶어.
필요한 화면을 모두 예시 데이터로 만들어줘. 로그인이나 저장 같은 기능은 빼고 화면만 만들어.
디자인 스타일은 서비스에 어울리는 걸로 추천해주고, 다 만들면 HTML 파일로 내보내줘.
```

**같은 컨셉이라도 이름, 스타일, 화면은 매번 다르게 나와요.** 프리셋에 가깝게 만들려면 [프리셋 팩으로 만들어 보기](https://prokit-web.vercel.app/tutorials/samples/ullim/#프리셋-팩으로-만들어-보기)를 쓰세요.

에이전트를 아직 열지 않았으면 [1. 작업 폴더에서 에이전트 열기](https://prokit-web.vercel.app/tutorials/samples/#1-작업-폴더에서-에이전트-열기)부터 하세요. 프롬프트를 보낸 다음에는 [3. 알려 준 한 줄로 이어 가기](https://prokit-web.vercel.app/tutorials/samples/#3-알려-준-한-줄로-이어-가기)와 [4. 답하며 요청을 자세히 채우기](https://prokit-web.vercel.app/tutorials/samples/#4-답하며-요청을-자세히-채우기)를 따라가면 돼요.

## 시간과 비용

위 "프리셋 팩으로 만들어 보기" 프롬프트로 만들 때 **한 번에 완성하면 약 1시간 15분\~2시간 30분(여러 번 고쳐 달라고 하면 약 3시간 45분까지)** 걸리고, 토큰은 최소 **약 170만**(캐시 포함 약 8,300만)이 들어요. 팩 없이 [이 컨셉으로 처음부터](https://prokit-web.vercel.app/tutorials/samples/ullim/#이-컨셉으로-처음부터-만들기) 만들 때는 한 번에 완성하면 약 2시간 10분\~4시간 20분(여러 번 고쳐 달라고 하면 약 6시간 30분까지) 걸리고, 토큰은 최소 약 300만이 들어요.

## 실제로 거친 과정

울림은 한 번에 나오지 않았어요. 결과를 보고 몇 번 다시 요청했어요.

| 단계 | 한 일 | 결과 |
|---|---|---|
| 1. 기획 | 서비스 설명(`PRODUCT.md`)과 첫 화면 설계만 미리 적었어요. 스타일과 색은 적지 않고 원하는 인상(극적이고 시네마틱한 느낌)만 적었어요 | 이름은 울림 |
| 2. 첫 판 | 추천 후보(Sequel, Slash, Ciridae)와 직접 정하기 중 1위 Sequel을 고르고 대표 색은 원본 그대로 두었어요 | 디자인 리뷰 22/32 |

## 실제 서비스로 만들 때

울림은 음성 합성 서비스, 파일 저장소, 정기결제까지 외부 서비스가 세 가지 필요하고, 소셜 로그인을 붙이면 하나 더 늘어요.

바꾸는 순서는 [실제 서비스로 만들기](https://prokit-web.vercel.app/tutorials/samples/real-service/)를 따르고, **기능은 아래 요청을 하나씩 보내세요.**

**필요한 데이터**: 프로젝트(제목, 목소리, 수정한 때), 문장(순서, 글, 억양, 속도, 앞뒤 쉼, 감정, 챕터 시작 여부), 내보내기 기록(형식, 챕터 수, 길이, 파일), 구독(요금제, 결제 주기, 해지 예약), 결제 내역, 이번 달 사용 분량

**지킬 규칙**: 회원은 자기 프로젝트와 내보낸 파일만 봐요. 이번 달 분량이 모자라면 음성을 만들거나 내보낼 수 없어요.

```prompt
프로젝트와 문장을 DB에 저장하게 해줘. 회원은 자기 프로젝트만 볼 수 있어야 해. 새 프로젝트를 만들 때 붙여 넣은 대본을 문장으로 나눠 저장해.
```

```prompt
편집기에서 문장의 억양, 속도, 쉼, 감정을 바꾸면 DB에 저장되게 해줘. 고른 목소리를 바꾸면 프로젝트에도 저장해.
```

```prompt
문장마다 음성 합성 API로 음성을 만들어 재생할 수 있게 해줘. 바뀐 문장만 다시 만들고, 만든 분량은 이번 달 사용량에 더해.
```

```prompt
내보내기 창에서 고른 형식(MP3, WAV, 챕터 분할)으로 파일을 만들어 파일 저장소에 올리고, 내려받는 링크를 보여 줘. 내보낸 기록도 DB에 남겨.
```

```prompt
요금제 선택과 정기결제를 붙여줘. 결제하면 구독과 결제 내역을 DB에 저장하고, 요금제별 월 분량(10분, 3시간, 20시간)을 사용량 한도로 써.
```

> [!TIP]
> 울림 프리셋은 화면만 만들 때 이미 대본을 문장으로 나누는 코드(`apps/web/src/lib/manuscript.ts`의 `splitManuscript`)를 만들어 두었어요. 빈 줄은 챕터 경계로 처리해요. 내 프로젝트에도 비슷한 코드가 있으면 새로 만들지 말고 그대로 쓰자고 하세요.

외부 서비스는 계정과 키가 따로 필요해요. 음성 합성은 쓸 음성 합성 서비스의 API 키, 파일 저장은 저장소 서비스의 계정, 정기결제는 결제 대행사의 가맹 계정이 있어야 해요. 카카오로 로그인하려면 카카오 개발자 계정에서 앱을 등록해야 하고, 이메일 로그인만 쓰면 이 부분은 건너뛸 수 있어요. 키는 대화창에 붙여 넣지 마세요([비용과 키](https://prokit-web.vercel.app/tutorials/reference/costs-and-keys/)).
