# 다듬기
https://prokit-web.vercel.app/tutorials/samples/refine/

만든 화면을 고치는 프롬프트와, 스타일·색·서체를 처음부터 내가 정해 자세히 요청하는 법을 모았어요. 다듬기는 선택이에요. 에이전트가 추천한 대로 둬도 충분히 쓸 만한 화면이 나와요.

만든 뒤 고치는 프롬프트는 **화면을 만든 프로젝트 폴더**(예: `~/projects/living`)에서 연 에이전트에 보내세요. 처음부터 자세히 요청하는 내용은 [가장 쉬운 방법](https://prokit-web.vercel.app/tutorials/samples/#가장-쉬운-방법)의 프롬프트에 넣어 작업 폴더에서 보내요.

> [!NOTE]
> 괄호 안의 프리셋 이름은 그 프리셋이 이렇게 만들어졌다는 뜻이에요. "실제 요청"은 프리셋을 만들 때 실제로 보낸 요청이에요.

## 1. 살펴볼 곳

에이전트는 아래 세 카탈로그에서 스타일을 추천해요. 미리 둘러보고 마음에 드는 스타일을 골라 두면 내 취향에 더 가깝게 요청할 수 있어요.

| 곳 | 볼 수 있는 것 | 요청하는 법 |
|---|---|---|
| [Refero Styles](https://styles.refero.design) | 해외 웹사이트 1,342곳의 스타일. 스타일마다 미리 보기, 분위기 한 줄, 색 팔레트, 글자 크기 단계, 버튼·카드 같은 부품이 있어요. AI 스타트업, 핀테크, 쇼핑몰, 다크 모드, 미니멀, 에디토리얼, 생산성 앱, 서체 조합 등 11개로 나뉘어 있어요 | 스타일 페이지 주소를 붙여 넣어요 |
| [awesome-design-md](https://github.com/VoltAgent/awesome-design-md) | 해외 제품 74개(AI, 개발자 도구, 핀테크, 커머스, 자동차 등)의 색, 서체, 레이아웃, 모서리, 부품 | 제품 이름이나 주소 |
| [getdesign.kr](https://www.getdesign.kr) | 토스, 당근, 배달의민족, 원티드, 여기어때 등 한국 서비스 23개의 색, 서체, 간격, 모서리, 그림자, 움직임, 부품 | `토스처럼` |
| 서체: [Google Fonts 한글](https://fonts.google.com/?subset=korean), [눈누](https://noonnu.cc) | 무료 한글 서체. 눈누는 서체마다 상업적으로 써도 되는 범위가 달라서 꼭 확인해요 | 서체 이름 |

> [!TIP]
> 에이전트는 이 세 카탈로그에서만 스타일을 가져와요. 목록에 없는 브랜드를 말하면 없다고 알려 주고 비슷한 후보를 다시 골라 줘요.

## 2. 살펴본 것을 프롬프트로 옮기기

정할 수 있는 것과 예시 문장이에요. 필요한 줄만 골라 처음 프롬프트의 서비스 부분에 붙이거나, 다 만든 뒤 따로 보내세요.

| 정할 것 | 이렇게 써요 |
|---|---|
| 스타일 통째로 | `디자인은 이 스타일로 해줘: <스타일 페이지 주소>`, `토스처럼 만들어줘` |
| 스타일 하나를 바탕으로 일부만 바꾸기 | `바탕은 Monzo로 하고 대표 색만 홍시색으로 바꿔줘`(고루) |
| 대표 색 | `대표 색은 스타일 원본 그대로`, `대표 색은 깊은 초록으로`. 같은 업종의 브랜드 스타일을 고르면 그 회사와 헷갈리지 않게 색을 바꾸는 게 좋아요 |
| 분위기 | `따뜻하고 다정하게, 장난스럽지 않게`, `잡지 표지처럼 큰 사진과 굵은 제목으로`(PACECREW), `관제실 모니터처럼 숫자를 크게`(Uptrail) |
| 서체 | `제목은 아주 굵은 고딕(Wanted Sans), 본문은 Pretendard`(고루), `인용 문구는 명조(Hahmlet)`(울림), `숫자와 코드는 고정폭(JetBrains Mono)`(Uptrail) |
| 구도와 밀도 | `이번 달 지출이 날짜 순서로 보이게`(고루), `데스크톱 폭을 넓게 써줘`, `여백 넉넉하게, 카드 모서리는 크게` |
| 사진과 그림 | `사람 사진 위주로`, `사진 없이 숫자와 그래프로`, `사진 말고 따뜻한 일러스트로` |
| 움직임 | `조용하게, 숫자가 올라가는 효과 정도만`, `스크롤하면 사진이 천천히 나타나게` |
| 기기와 말투 | `휴대폰 화면 먼저`, `해요체로 친근하게, 과장 없이` |

## 3. 한 번에 자세히 요청하기

[가장 쉬운 방법](https://prokit-web.vercel.app/tutorials/samples/#가장-쉬운-방법)의 프롬프트에서 서비스 부분(`[같이 사는 사람들이…]`가 있는 줄부터 끝까지)을 이렇게 바꿔 보내면 처음부터 내가 정한 대로 만들어요. 고루와 비슷하게 만들고 싶을 때의 예예요. 정하지 않은 것은 에이전트가 추천해요.

```prompt
같이 사는 2~4명이 함께 쓴 생활비를 적고, 월말에 송금 횟수가 가장 적게 정산해 주는 서비스야. 이름은 고루.
페이지는 홈, 지출 내역, 정산, 통계, 우리 집, 프로필, 시작하기(초대 코드로 참여) 7개로 해줘.
모든 화면을 예시 데이터로 만들고, 로그인이나 저장 같은 기능은 빼고 화면만 만들어.
디자인은 https://styles.refero.design/style/e8a1d114-6924-4f03-acd2-996dd30f15a6 (Monzo)를 바탕으로 하고 대표 색만 깊은 홍시색으로 바꿔줘.
제목은 아주 굵은 고딕(Wanted Sans), 본문은 Pretendard로 해줘.
홈에서는 내가 보낼 돈을 가장 크게 보여 주고, 이번 달 지출이 날짜 순서로 보이게 해줘.
분위기는 따뜻하고 다정하게, 말투는 해요체로 해줘.
다 만들면 HTML 파일로 내보내줘.
```

이름을 직접 정할 때는 같은 이름의 서비스가 있는지 확인해 달라고 하세요. 고루도 새로 고른 이름(Evenly)과 같은 분야 앱이 앱 스토어에 있어서 다시 바꿨어요.

## 4. 만든 뒤 고치기

결과를 보고 마음에 안 드는 곳을 말로 적으면 돼요. "어디가 어떻게"를 함께 쓰면 더 정확하게 고쳐요.

### 스타일과 색

```prompt
다른 스타일 후보 3개를 더 보여줘. 이번에는 지금과 다른 계열로.
```

> [!WARNING]
> 다 만든 뒤 스타일을 바꾸면 모든 페이지를 다시 만들어요. 시간과 사용량이 처음만큼 들어요. 색이나 글자 크기만 바꾸는 건 금방 끝나요.

```prompt
대표 색을 우리 서비스 색 #2f6f4f로 바꾸고, 그 색 위의 흰 글자도 잘 읽히게 맞춰줘.
```

```prompt
제목 글자가 가늘고 작아. 더 굵고 크게 바꿔줘.
```

### 이름과 문구

```prompt
서비스 이름 후보를 10개 더 내줘. 비슷한 서비스의 이름을 조사하고, 같은 이름의 앱이 있는지도 확인해줘.
```

고루는 이렇게 같이살림 → Evenly → 고루로 이름이 바뀌었어요.

```prompt
첫 화면 문구 후보를 다시 내줘. 전기요금 부담이 줄어든다는 내용을 꼭 넣어줘.
```

AFTERGLOW는 이 요청으로 첫 화면 문구가 "전기요금은 가볍게, 정전에도 든든하게"가 됐어요.

```prompt
화면에 나오는 '원고'를 모두 '대본'으로 바꿔줘.
```

울림은 이렇게 화면 70곳(조사 포함)의 말을 한 번에 바꿨어요.

### 구도와 화면

```prompt
지금 화면은 평범한 관리자 화면 같아. 글자가 작고 위계가 약하고, 데스크톱 폭을 못 써.
서비스다운 인상이 나게 리디자인해줘.
```

고루의 실제 요청을 줄인 거예요. 핏슬롯, Uptrail, 하루공부도 지금 화면의 아쉬운 점을 이렇게 적어 보내서 다시 만들었어요.

```prompt
A안으로 하되, 아래쪽 두 단은 B안처럼 아이콘과 함께 읽기 쉽게 해줘.
```

고루의 실제 요청을 줄인 거예요. 시안을 섞어 고를 수 있어요.

```prompt
휴대폰에서는 아래쪽에 고정 버튼과 탭을 넣어줘.
```

### 페이지와 동작

```prompt
자주 묻는 질문 페이지를 더해줘. 메뉴와 맨 아래 링크에서 갈 수 있게.
```

```prompt
목록 항목을 누르면 오른쪽에서 상세 창이 열리게 하고, 지울 때는 확인 창을 띄워줘.
```

```prompt
모든 페이지의 링크와 버튼을 눌러 보고, 안 열리거나 반응 없는 게 있으면 고쳐줘.
```

### 사진 (이미지를 그릴 수 있을 때)

```prompt
인물 사진을 원본 크기로 하나씩 보고, 팔다리나 손가락이 이상한 사진은 다시 만들어줘.
```

PACECREW는 이런 요청으로 인물 사진 7장을, 울림과 제철상자는 4장씩 다시 만들었어요.

```prompt
첫 화면 큰 사진을 다시 만들어줘. 저녁 식탁에 둘러앉은 사람들로, 얼굴은 크게 나오지 않게.
```

Codex, Antigravity, Grok Build는 자체 도구로 그리고, Claude Code는 ChatGPT 유료 요금제(Codex CLI)나 OpenAI API 키를 준비해야 그려요([이미지 그리기](https://prokit-web.vercel.app/tutorials/reference/costs-and-keys/#이미지-그리기)). 그릴 수 없으면 내가 가진 사진을 쓰거나, 사진 없이도 보기 좋은 구성으로 바꿔 달라고 하세요.

```prompt
사진 없이도 보기 좋은 구성으로 바꿔줘.
```
