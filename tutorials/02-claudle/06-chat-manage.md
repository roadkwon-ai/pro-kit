# 6장. 대화 관리

## 이번 장에서 할 일

사이드바 대화 목록의 고정, 이름 바꾸기, 삭제를 DB에 저장해요. 목록은 위의 "고정됨"과 아래의 "이전" 두 구역으로 나뉘어요. **4장에서는 화면에서만 바뀌던 것이 이제 새로고침해도 남아요.**

## 1. 고정, 이름 바꾸기, 삭제

5장의 확인을 마친 에이전트에 보내요.

```prompt
대화 목록을 프리셋 팩 features.md "대화 목록 관리"대로 만들어줘.
고정, 이름 바꾸기, 삭제를 실제로 저장하고, 행 메뉴와 대화 제목 메뉴 둘 다에서 되게 해줘.
삭제는 확인 창을 거친 뒤 메시지까지 함께 지워줘.
```

에이전트는 이런 순서로 일해요.

1. [스펙](../reference/glossary.md#만들기)(<!-- v:gloss.spec -->기능의 범위와 동작을 적은 문서<!-- /v -->)을 보여 주며 확인을 받아요.
2. 고정 시각을 더하는 [마이그레이션](../reference/glossary.md#만들기)(<!-- v:gloss.migration -->DB의 표를 만들거나 바꾸는 기록<!-- /v -->)을 만들어 적용해요.
3. 목록을 두 구역으로 나누고, 고정·이름 바꾸기·삭제 서버 기능을 만들어요.
4. 다른 계정의 대화를 고정하거나 지울 수 없는지 자동 테스트로 확인해요.
5. 리뷰를 마치면 개발 서버를 켜 두고 확인을 요청해요.

**이렇게 되면 성공**
- 대화를 고정하면 "고정됨" 구역으로 올라가고, 새로고침해도 남아요.
- 이름을 바꾼 대화는 새 메시지를 보내도 자동 제목으로 돌아가지 않아요.
- 삭제를 누르면 확인 창이 뜨고, 지운 뒤에는 목록에서 사라져요. 지운 대화 주소로 열면 찾을 수 없다고 나와요.

괜찮으면 `확인했어`라고 보내세요.

<details>
<summary>막히면</summary>

- **이름을 바꿨는데 다시 첫 질문으로 돌아가요**: `features.md "대화 목록 관리"대로 사용자가 바꾼 제목은 자동 제목이 덮어쓰지 않게 해줘`라고 보내세요.
- **고정한 순서가 뒤죽박죽이에요**: `고정됨 구역은 고정한 시각 순으로 보여 줘`라고 보내세요.
- **삭제했는데 메시지가 DB에 남아요**: `대화를 지우면 메시지도 함께 지워지게 해줘`라고 보내세요.
- **프리셋 팩을 못 찾거나, 앞 장 작업을 이어서 하려 하거나, 중간에 멈췄어요**: [5장의 막히면](05-auth-chats.md#3-직접-써-보고-확인하기)과 같아요.
- 그 밖의 문제는 [막혔을 때](../reference/troubleshooting.md)를 보세요.

</details>
