# 8장. 대화 검색

## 이번 장에서 할 일

`⌘K`(Windows는 `Ctrl+K`)로 여는 검색 창이 내 대화의 제목과 내용을 실제로 찾게 해요. **4장에서는 예시 데이터에서만 찾았지만, 이제 DB에 저장한 내 대화에서 찾아요.**

## 1. 대화 검색 만들기

7장의 확인을 마친 에이전트에 보내요(7장을 건너뛰었다면 6장).

```prompt
검색 창을 프리셋 팩 features.md "검색"대로 만들어줘. 내 대화의 제목과 내용에서 찾아.
한글 두 글자로도 찾아지게 해줘. 결과 행을 누르면 그 대화로 가.
```

에이전트는 이런 순서로 일해요.

1. [스펙](../reference/glossary.md#만들기)(<!-- v:gloss.spec -->기능의 범위와 동작을 적은 문서<!-- /v -->)을 보여 주며 확인을 받아요.
2. 글자 조각으로 빨리 찾는 색인을 만드는 [마이그레이션](../reference/glossary.md#만들기)(<!-- v:gloss.migration -->DB의 표를 만들거나 바꾸는 기록<!-- /v -->)을 적용해요.
3. 검색 서버 기능을 만들고, 검색 창의 결과를 DB 결과로 바꿔요.
4. 다른 계정의 대화가 결과에 나오지 않는지 자동 테스트로 확인해요.
5. 리뷰를 마치면 개발 서버를 켜 두고 확인을 요청해요.

**이렇게 되면 성공**
- 한글 두 글자(예: "일정")로 제목과 내용이 모두 찾아져요.
- 결과를 누르면 그 대화가 열리고, `Esc`로 닫으면 원래 자리로 돌아와요.
- 다른 계정의 대화는 결과에 나오지 않아요.

괜찮으면 `확인했어`라고 보내세요.

<details>
<summary>막히면</summary>

- **한 글자나 두 글자로는 안 찾아져요**: `한글 두 글자로도 찾아지게 features.md "검색"의 방법대로 고쳐줘`라고 보내세요.
- **다른 계정의 대화가 나와요**: `검색이 남의 대화까지 찾아. 내 대화만 찾게 고치고 테스트를 더해줘`라고 보내세요.
- **프리셋 팩을 못 찾거나, 앞 장 작업을 이어서 하려 하거나, 중간에 멈췄어요**: [5장의 막히면](05-auth-chats.md#3-직접-써-보고-확인하기)과 같아요.
- 그 밖의 문제는 [막혔을 때](../reference/troubleshooting.md)를 보세요.

</details>
