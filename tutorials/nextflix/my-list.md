# 8장. 찜
https://prokit-web.vercel.app/tutorials/nextflix/my-list/

## 이번 장에서 할 일

작품의 + 버튼으로 담는 찜을 DB에 저장해요. 프로필마다 따로 담고, 나의 Nextflix 화면과 홈의 찜 줄에 보여 줘요. "나의 Nextflix"에는 내가 정한 서비스 이름이 들어가요.

이어서 같은 방식으로 작품의 저장 버튼(다운로드)과 알림 받기도 프로필마다 저장해요. **실제 영상 파일은 내려받지 않고, 알림은 메일 없이 화면 안에만 보여 줘요.**

## 1. 찜 저장하기

7장의 확인을 마친 에이전트에 보내요. 서비스 이름을 바꿨다면 `[Nextflix]`도 바꾸세요.

```prompt
찜을 실제로 저장되게 해줘. 프리셋 팩 features.md "찜·평가·다운로드·알림"의 찜 규칙대로 프로필마다 따로 담고, 나의 [Nextflix] 화면과 홈의 찜 줄에 보여줘.
어린이 프로필이면 등급 상한을 넘는 작품은 찜 줄에서도 빼줘.
```

[프리셋 팩](https://prokit-web.vercel.app/tutorials/reference/glossary/#만들기)은 만들 서비스의 화면 구성, 기능 규칙, 디자인 노트, 예시 데이터, 그림을 묶어 둔 폴더예요. 에이전트는 이런 순서로 일해요.

1. [스펙](https://prokit-web.vercel.app/tutorials/reference/glossary/#만들기)(기능의 범위와 동작을 적은 문서)을 보여 주며 확인을 받아요.
2. 찜 표를 만드는 [마이그레이션](https://prokit-web.vercel.app/tutorials/reference/glossary/#만들기)(DB의 표를 만들거나 바꾸는 기록)을 만들어 적용해요.
3. 찜을 담고 빼는 서버 기능을 만들어요. 고른 프로필은 5장에서 만든 방식 그대로 확인해요.
4. 두 계정으로 서로의 찜을 보거나 바꿀 수 없는지 자동 테스트로 확인해요.
5. 버튼을 누르면 바로 바뀌고, 저장에 실패하면 되돌아가게 화면을 바꿔요.
6. 리뷰를 마치면 개발 서버를 켜 두고 확인을 요청해요.

처음에는 찜 줄이 비어 있어요. 4장의 예시 찜 대신 내가 담은 작품이 나와서예요. 홈의 찜 줄은 비면 숨고, 나의 Nextflix에는 담는 법을 알려 주는 안내가 나와요.

**이렇게 되면 성공**
- 담고 새로고침해도 남아 있어요.
- 다른 프로필에는 보이지 않아요.
- 최근에 담은 것이 앞에 와요.

![프리셋 사이트의 나의 Nextflix 화면](https://prokit-web.vercel.app/images/tutorials/01-nextflix/nextflix-my.webp)

프리셋 사이트의 나의 Nextflix 화면이에요(예시 데이터가 미리 들어 있어요). 위쪽 "저장한 콘텐츠 관리"는 2절에서 만드는 저장 목록으로 가요. 이 장을 마치면 이 화면이 실제로 동작해요.

괜찮으면 `확인했어`라고 보내세요.

<details>
<summary>막히면</summary>

- **누르면 바뀌었다가 잠시 뒤 되돌아가요**: 저장에 실패하고 있을 때예요. `찜 버튼을 누르면 되돌아가. 서버 저장이 왜 실패하는지 확인하고 고쳐줘`라고 보내세요.
- **다른 프로필에도 같은 찜이 보여요**: `찜이 프로필마다 따로 저장되지 않아. 고른 프로필로만 저장되게 고쳐줘`라고 보내세요.
- **찜 줄에 예시 작품이 그대로 있어요**: `찜 줄이 예시 데이터를 보여 줘. 내 프로필의 찜으로 바꿔줘`라고 보내세요.
- **프리셋 팩을 못 찾거나, 앞 장 작업을 이어서 하려 하거나, 중간에 멈췄어요**: [5장의 막히면](https://prokit-web.vercel.app/tutorials/nextflix/auth-profiles/#3-직접-써-보고-확인하기)과 같아요.
- 그 밖의 문제는 [막혔을 때](https://prokit-web.vercel.app/tutorials/reference/troubleshooting/)를 보세요.

</details>

## 2. 저장한 콘텐츠와 알림

1절의 확인을 마친 에이전트에 보내요. 에이전트는 이 기능으로 [라운드](https://prokit-web.vercel.app/tutorials/reference/glossary/#만들기)를 새로 열어요.

```prompt
작품의 저장 버튼도 프리셋 팩 features.md "찜·평가·다운로드·알림"의 다운로드 규칙대로 실제로 저장해줘. 찜처럼 프로필마다 저장 목록과 상태만 저장하고, 영상 파일은 내려받지 마.
알림 받기도 같은 절의 규칙대로 저장하고, 공개 예정 작품이 공개되거나 라이브가 시작되면 그 프로필에 알림을 만들어줘. 메일은 보내지 마.
공개와 라이브 시작은 확인할 때 내 컴퓨터에서만 쓰는 명령으로 바꾸게 해줘.
```

**이렇게 되면 성공**
- 저장 버튼을 누르면 "저장 중"을 거쳐 "저장됨"이 되고, 새로고침해도 저장한 콘텐츠 관리 화면에 남아요.
- 다른 프로필의 저장 목록에는 보이지 않아요.
- 알림 받기를 누른 작품이 공개되면 헤더 알림에 새 알림이 생겨요. 공개해 보는 방법은 에이전트가 확인 순서와 함께 알려 줘요.

괜찮으면 `확인했어`라고 보내세요.

## 더 해 보기

2절의 확인을 마친 뒤 보내면 에이전트가 라운드를 새로 열어요.

### 알림을 메일로도 보내기

> [!TIP]
> 화면 안 알림이 생길 때 메일도 보내요. 메일 발송 서비스(예: Resend) 계정과 API 키가 필요해요.

```prompt
알림이 생기면 메일로도 보내줘. 팩은 고치지 말고, 이 프로젝트에서는 features.md "찜·평가·다운로드·알림"에서 메일을 보내지 않는다는 부분만 이 기능으로 바꿔줘.
메일 발송 서비스는 Resend를 쓰고, 키는 .env에만 둬. 계정 화면에서 프로필마다 알림 메일을 끌 수 있게 해줘.
```

## 에이전트가 물어보면

5장처럼 [라운드](https://prokit-web.vercel.app/tutorials/reference/glossary/#만들기)(기능 하나를 만들거나 요청한 것을 고치고 확인까지 마치는 작업 묶음) 하나로 진행되고, 끝에 직접 써 보고 확인해 달라고 해요. [4장](https://prokit-web.vercel.app/tutorials/nextflix/screens/#에이전트가-물어보면)과 [5장](https://prokit-web.vercel.app/tutorials/nextflix/auth-profiles/#에이전트가-물어보면) 표의 질문(디자인 점수, 스킬 업데이트 등)도 나올 수 있어요. 선택지 창에서 답하는 법은 [질문에 답하는 법](https://prokit-web.vercel.app/tutorials/reference/claude-code-and-codex/#질문에-답하는-법)에 있어요.

| 질문 | 답 |
|---|---|
| 스펙을 확인해 달라 | 읽어 보고 `좋아, 진행해줘` 또는 고칠 곳 |
| 계획을 확인하고 구현 방식을 골라 달라 | `추천대로 해줘` |
| 직접 써 보고 확인해 달라 | 프로필 두 개로 담아 본 뒤 `확인했어` 또는 고칠 곳 |
